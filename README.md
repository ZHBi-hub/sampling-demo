# 抽样定理与 sinc 内插复原

面向《光信息处理》课程“抽样定理与空间带宽积”教学单元的交互式仿真工具，用于比较不同采样间隔下正弦信号与 sinc 内插的重建效果。

## 在线使用

**演示地址：** https://zhbi-hub.github.io/sampling-demo/

页面为单文件 HTML，无需登录、安装插件或额外依赖。

## 主要功能

- 调整采样间隔并观察采样点变化
- 切换待重建函数
- 对比原函数与 sinc 内插结果
- 实时查看重建误差与采样状态
- 一键重置参数

## 本地运行

直接双击 `index.html`，或在本目录启动任意静态文件服务器。

## 兼容性

建议使用近两年版本的 Edge、Chrome、Firefox 或 Safari。移动端需支持 Pointer Events。
