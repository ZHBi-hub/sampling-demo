# 抽样定理仿真工具：托管与二维码说明

## 一、包内文件

- `index.html`：单文件交互仿真工具，无外部依赖，可离线运行。
- `make_qrcode.py`：输入公开链接，生成带中文标签的二维码 `tool_qrcode.png`。
- `README-部署说明.md`：本文件。

## 二、托管方式（任选其一）

### 方式A：GitHub Pages（推荐，免费稳定）

1. 新建一个公开仓库，例如 `sampling-demo`。
2. 上传 `index.html` 到仓库根目录。
3. 进入 Settings → Pages → Build and deployment：
   - Source 选 `Deploy from a branch`
   - Branch 选 `main`，目录选 `/ (root)`
4. 等待1—2分钟，访问 `https://<你的用户名>.github.io/sampling-demo/`。
5. 用手机和电脑各打开一次，确认无需登录、无需插件、滑块可操作。

### 方式B：学校课程平台/云盘公开链接

1. 上传 `index.html`。
2. 设置为“公开可读/任何人可访问”，复制直链。
3. 用无痕窗口打开，确认不是“需要登录”的页面。

### 方式C：对象存储静态网站

- 腾讯云COS/阿里云OSS：上传 `index.html`，设置公共读，开启静态网站托管，使用分配的访问地址。
- 注意：部分对象存储默认下载而不是预览，需设置 `Content-Type: text/html`。

## 三、生成二维码

```bash
python make_qrcode.py "https://你的公开链接/"
```

生成 `tool_qrcode.png`，可直接插入申报书“六、补充材料”第2条下方或图1下方。

## 四、写进申报书的话术

> 交互式仿真工具“抽样定理·sinc内插复原”已托管为公开网页，扫码即可运行，无需安装插件；同时保留单文件HTML离线备份，防止现场网络故障。

## 五、课堂使用建议

- 课前1天在教室电脑打开一次，确认投影比例与浏览器兼容。
- 保留离线HTML到U盘/桌面，网络故障时直接双击打开。
- 学生手机扫码时，提醒不要上传任何个人或未公开文化素材。
- 截图命名：`班级-组号-状态-参数.png`，便于课后归档。
